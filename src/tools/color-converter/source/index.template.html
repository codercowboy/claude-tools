    How Color Converter works

    Paste or type colors — rgba() (or rgb()) and hex, mixed together is fine — one per line, into the box at the top, then tap Convert to turn each line into its own row below with a live color swatch and both formats.

    • Convert. Replaces the rows below with a fresh row for every non-blank line you pasted or typed — swatch, hex, and rgba are generated for each. Lines that can't be parsed as a color get an INVALID: … row instead, so you can find and fix them.
    • Rows. Each row shows a swatch preview plus editable hex and rgba fields with their own copy (📋) buttons — edit a row's input directly and its swatch and fields update as you type. Add row starts a new blank row; the trash icon removes a single row (asks you to confirm first).
    • Copy all. The Hex and RGBA output boxes list every row's value, one per line, in the order the rows appear — use their "Copy all" buttons to grab the whole list at once.
    • Clear / Remove all. Clear empties the paste box; Remove all empties every row. Both ask you to confirm first, since they can't be undone.

    Your rows and the paste box's text are saved on this device, so they're still here next time you open Color Converter.
