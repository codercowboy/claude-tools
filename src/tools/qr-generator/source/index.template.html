How QR Code Generator works

Type or paste text — or a URL — into the box above and a QR code is generated for you automatically, entirely in your browser. There's no library or server call involved: the encoder (error correction, masking, and all) is hand-rolled from the ISO/IEC 18004 spec.

  • Error correction level. Higher levels (Q, H) let the code keep scanning even if part of it gets damaged or obscured, at the cost of a denser code. H (~30% recovery) is the default.
  • Module scale & quiet zone. Scale sets how many pixels each square module renders at; quiet zone sets the blank border (in modules) most scanners expect around the code.
  • Foreground & background color. Customize the code's colors — a warning appears if the contrast between them gets too low to scan reliably.
  • Download PNG or SVG. Save the generated code as a pixel PNG or a scalable SVG. Both files carry small embedded credit metadata (author "claude tools" and the project's GitHub URL) — the PNG via standard tEXt chunks, the SVG via an XML comment and a <metadata> block — the QR code's own pixels/geometry are never touched.

Your text and options are saved on this device, so they're still here next time you open QR Code Generator.
