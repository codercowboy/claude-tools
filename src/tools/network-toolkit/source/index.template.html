Network Toolkit

Four independent networking calculators. Everything runs locally in your browser — there are no DNS lookups, no pings, and no network requests of any kind. Nothing you type is ever sent anywhere.

  • Transfer Time & Rate. Enter an amount and a speed to get the transfer time, plus a table of how long 1 MB → 1 PB take at that speed. Amounts and speeds accept any bit or byte unit; bit ↔ byte is always ×8. The Decimal (1000) / Binary (1024) toggle sets the prefix base — network rates are conventionally decimal (Mbps = 1,000,000 bit/s), while file sizes are often binary; pick whichever you mean.
  • CIDR / Subnet. An IPv4 address + prefix gives netmask, wildcard, network, broadcast, first/last usable host, and host counts. /31 (point-to-point) has 2 usable hosts and /32 has 1 — broadcast isn't meaningful there.
  • IP Converter. Edit any field and the rest follow. IPv4: dotted ⇄ integer ⇄ hex ⇄ binary. IPv6: compressed ⇄ expanded ⇄ hex, with :: zero-compression and embedded-IPv4 input.
  • Netmask ⇄ Prefix. Dotted mask to /prefix and back. A non-contiguous mask (e.g. 255.0.255.0) is rejected.
  • Copy buttons (📋). Each value has an in-field copy button; each card has a Copy all.

Your inputs and unit choices are remembered on this device, so reopening the tool picks up where you left off.
