## Build tokens

- Template `<style>`: `<<ct:include base.css>><<ct:include controls.css>><<ct:inline styles.css>>`.
- Footer: `<<ct:include footer.html>>`.
- copy.js in a plain `<script>`: `<<ct:include copy.js>>`.
- App module: `<script type="module"><<ct:inline app.mjs>></script>`, and
  `app.mjs` begins with `<<ct:inline logic.mjs>>`.

## Steps

1. **logic.mjs** — pure functions per DESIGN surface. Number/BigInt exact math;
   32-bit ops via `>>> 0`; IPv6 via 128-bit BigInt. Friendly `Error` messages.
2. **index.template.html** — head (title, og/twitter meta), header (title +
   `?` help button), four `<section class="card">` blocks with `data-testid`s,
   help overlay/dialog with `modal-close-x`, footer + script tokens.
3. **styles.css** — palette tokens (light + dark), card/field/table/modal
   styling, in-field-copy padding reserve, responsive + wide-screen rules.
4. **app.mjs** — inline logic; state + persistence (`network-toolkit:v1`);
   per-card render + wiring; delegated copy buttons; editable-copy reveal; help
   modal (focus trap, Esc/backdrop, `✕`); init/restore; `window.__networkToolkit`.
5. **README.md**, **package.json** (from base64-tool template).
6. **Build & self-check:** `npm run build && npm run build:check` (both exit 0);
   `node -e` sanity on `cidrInfo`, `ipv4ToInt` round-trip, `ipv6Compress`,
   `maskToPrefix`, `transferTime`.

## Correctness targets (for the later unit suite)

- `ipv4ToInt('192.168.1.10')` = 3232235786; round-trips via `intToIpv4`.
- `cidrInfo('192.168.1.10', 24)`: network `192.168.1.0`, broadcast
  `192.168.1.255`, first `192.168.1.1`, last `192.168.1.254`, usable 254.
- `/31` → 2 usable; `/32` → 1 usable; `/0` → 4294967294 usable.
- `maskToPrefix('255.255.255.0')` = 24; `255.0.255.0` throws.
- `ipv6Compress('2001:0db8:0000:0000:0000:0000:0000:0001')` = `2001:db8::1`;
  `ipv6Expand('::1')` = `0000:…:0001`.
- `transferTime(1,'GB',100,'Mbps',1000)` ≈ 80 s (1 GB = 8e9 bits ÷ 1e8 bps).
