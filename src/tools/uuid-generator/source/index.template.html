UUID Generator

UUID v4 & v7, ULID, nanoid, and random tokens — generate in bulk or inspect one. All local, nothing leaves your browser.

    About the UUID Generator

    Everything runs locally in your browser — nothing is ever sent anywhere. All randomness comes from crypto.getRandomValues, so this works identically opened from a file or served over plain HTTP on a LAN.

    Generate

    • Pick an ID type — UUID v4 (random), UUID v7 (time-ordered, sortable), ULID (time-sortable, Crockford base32), nanoid (compact, URL-safe), or a generic Token.
    • Set a Count (1–1000) and click Generate for a fresh batch.
    • UUID options: Uppercase, Hyphens on/off, and a Wrap style (plain, quoted, or braces).
    • nanoid / Token: set the Length; Tokens also choose an alphabet (Hex, Base62, Base64URL, or a Custom set).
    • Copy any single value with its 📋 button, or Copy all to grab the whole list (one per line).

    Inspect

    • Paste a UUID (hyphens, braces, or a urn:uuid: prefix are all fine) to see its version, variant, field breakdown, and validity.
    • For v1 and v7 UUIDs the embedded timestamp is decoded and shown.

    Your selected type, count, and options are remembered on this device — the generated values themselves are not stored (they're throwaway; just click Generate again).
