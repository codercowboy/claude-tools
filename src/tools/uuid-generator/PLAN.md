## Step 1 — `source/logic.mjs` (pure, DOM-free)

Wrap in `PURE-LOGIC` comments is optional; export everything. Implement:

1. Constants: `CROCKFORD`, `NANOID_ALPHABET` (official 64-char url alphabet),
   `TOKEN_ALPHABETS = { hex, base62, base64url }`, `VERSION_NAMES`.
2. `formatUuidBytes(b)` helper → canonical lowercase `8-4-4-4-12` from 16 bytes.
3. `uuidV4(bytes)` — copy 16 bytes, set version/variant nibbles, format.
4. `uuidV7(time, bytes)` — pack 48-bit big-endian ms (split high-16/low-32 to
   stay within 32-bit shifts), copy random bytes for the rest, set version 7 +
   variant, format.
5. `bytesToCrockford(bytes, numChars)` — big-endian 5-bit stream (flush often so
   the accumulator stays < 2^13).
6. `encodeTimeCrockford(time, len)` — 10-char timestamp via repeated `% 32`.
7. `ulid(time, bytes)` — `encodeTimeCrockford(time,10) + bytesToCrockford(bytes,16)`.
8. `nanoid(size = 21, bytes, alphabet = NANOID_ALPHABET)` — per-char
   `alphabet[bytes[i] % alphabet.length]`.
9. `randomToken(len, alphabet, bytes)` — same mapping over an explicit alphabet.
10. `inspectUuid(str)` — normalize (`urn:uuid:`/`{}`/hyphens/case → 32 hex),
    validate, derive version, variant (nibble bit-pattern), nil/max, and decode
    v1 (BigInt Gregorian 100-ns → Date) and v7 (48-bit ms → Date) timestamps;
    build the 5-field breakdown.
11. `export { … }` all of the above.

## Step 4 — `source/app.mjs`

1. DOM refs.
2. `state` + `STORAGE_KEY='uuid-generator:v1'` + `HELP_SEEN_KEY` with
   `loadState`/`saveState`/`hasSeenHelp`/`markHelpSeen` (all try/catch). Persist
   everything except `values`.
3. `<<ct:inline logic.mjs>>` (fold the pure engine in).
4. Byte source: `getRandomBytes(n)` — `crypto.getRandomValues` (chunked at
   65536), `Math.random` fallback only if `crypto` absent. **No `randomUUID`.**
5. `currentAlphabet()`, `generateOne(type)`, `applyUuidFormat(str)` (uppercase /
   hyphens / wrap), `generateBatch()` (clamp count 1–1000).
6. Rendering: `renderResults()` (build list rows + wire per-row copy),
   `renderInspect()` (debounced), option-group visibility per type.
7. Events: mode toggle, type toggle, count/length/alphabet/custom/toggles →
   update state + save + regenerate shape; Generate button → fresh batch (blur to
   dismiss mobile keyboard); Copy all; inspect input.
8. Help modal (open/close/focus-trap/Esc/backdrop/return) — mirror base64-tool.
9. `init()` — restore state, set mode/type, first `generateBatch()` +
   `renderInspect()`, auto-show Help once.
10. `window.__uuidGenerator = { uuidV4, uuidV7, ulid, nanoid, randomToken,
    inspectUuid, constants, getRandomBytes, generateBatch, setType, setMode,
    state }`.
