## Step 1 — `source/logic.mjs` (pure engine)

Hand-roll, all over `Uint8Array`:

1. `textToBytes`, `bytesToHex`, `bytesToBase64` (hand-rolled, no btoa).
2. `crc32` (table-driven, `0xEDB88320`) + `crc32Hex`.
3. Shared `padMessage(msg, blockSize, littleEndianLen)` — append `0x80`, zero
   fill to leave room for the length field, write the 64-bit bit-length
   (LE for MD5, BE for SHA-*; SHA-512's 128-bit field has zero upper 8 bytes).
4. `md5` (LE words, sine-table K, per-round shifts).
5. `sha1` (BE, 80-round schedule).
6. `sha256` (BE, 64 K constants).
7. `sha512` (BigInt, 64-bit masked, 80 K constants, 128-byte block).
8. `hmac(hashName, keyBytes, msgBytes)` — block-size map, key shorten/pad,
   ipad/opad `0x36`/`0x5c`, two-pass.
9. `export { … }` all of the above.

**Verify against vectors** (empty, "abc", "123456789", HMAC-SHA256 fox) before
moving on.

## Step 2 — `source/index.template.html`

Head: charset/viewport, `<title>Hasher</title>`, og:* + twitter:card meta,
`:root` light palette + `@media (prefers-color-scheme: dark)`, `* {box-sizing}`,
`<<ct:include base.css>><<ct:inline styles.css>>`.

Body:
- Header (`h1` + subtitle + `?` help button).
- Mode toggle (Text / File) `role="group"`.
- Text section: labelled textarea + Clear.
- File section (`hidden` unless File mode): dropzone + hidden file input +
  file-info (name · size · remove ✕) + size warning/error `aria-live`.
- Options: algorithm checkboxes (MD5, SHA-1, SHA-256, SHA-512, CRC32),
  "Also show Base64 (SHA family)" checkbox, "HMAC (SHA family)" checkbox + key
  field (hidden until enabled).
- Results: `aria-live` summary + a container the app fills with rows + "Copy all".
- Help overlay (dialog + pinned ✕), footer include, `copy.js` include,
  `<script type="module"><<ct:inline app.mjs>></script>`.

`data-testid` on everything interactive.

## Step 3 — `source/app.mjs`

- DOM refs; `state` (mode, sourceFile, in-memory hmac key/on); `<<ct:inline
  logic.mjs>>`.
- Persistence: `hasher:v1` load/save (mode, inputText, algorithms, showBase64
  only — never key/hmac/file); help-seen flag.
- Mode toggle, file drop/choose/remove, size guard.
- `recompute()` (async): resolve source bytes (text or file ArrayBuffer), for
  each enabled algo compute hex (+ base64 for SHA rows; HMAC for SHA rows when
  keyed), render rows with per-row copy; empty input ⇒ placeholders.
- Copy handlers (`copy`/`flash` from JbcClipboardUtil) incl. Copy all.
- Help modal (focus trap, Esc/backdrop, ✕, focus-return).
- `init()` restore + first-load help; `window.__hasher` hook.
