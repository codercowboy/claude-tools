## 1. `source/logic.mjs` — the pure parser (DOM-free)

Everything here is deterministic and importable by unit tests. Exports:
`mdToHtml`, `escapeHtmlForMarkdown`, `escapeAttrForMarkdown`, `sanitizeUrl`, `parseInline`,
`SAMPLE_MARKDOWN`.

**Escaping / URLs**
- `escapeHtmlForMarkdown(s)` — `& < > "` → entities.
- `escapeAttrForMarkdown(s)` — as above plus `'`.
- `sanitizeUrl(url, {allowImage})` — decode numeric/hex entities + strip control
  chars, inspect scheme; block `javascript:`/`vbscript:` (→ `""`), block `data:`
  for links (allow only `data:image/*` for images); otherwise return the original.

**Block parser** `parseBlocks(lines, refs)` — precedence loop:
blank → fenced code (``` / ~~~ + optional lang) → ATX heading → thematic break →
blockquote (collect `>` + lazy lines, recurse) → list (`parseList`, recurse) →
pipe table (`parseTable`, needs a delimiter row on line 2) → indented code (4
spaces) → paragraph (with setext `===`/`---` underline detection).
- `matchListItem(line)` — bullet/ordered, empty-item tolerant; returns
  indent/marker/ordered/contentIndent/content/startNum.
- `parseList` — group items at one indent, capture deeper-indented + lazy lines
  per item, detect loose vs tight (blank line between content), recurse
  `parseBlocks` on each dedented item; unwrap `<p>` for tight; task-list checkbox
  when an item starts `[ ]`/`[x]`; `start` attr for ordered lists not starting at 1.
- `parseTable` — split header + delimiter (alignment) + body rows on unescaped
  `|`; emit `thead`/`tbody` with `style="text-align:…"`; cells run `parseInline`.

**Inline parser** `parseInline(src, refs)` — stash-and-restore:
1. Left-to-right scan extracting, into placeholders holding final escaped HTML:
   backslash escapes, code spans (multi-backtick aware, spaces trimmed),
   autolinks (`<url>` / `<email>`), links + images (inline / reference / shortcut
   via `refs`, URL-sanitized, link text recursively inline-parsed).
2. `escapeHtmlForMarkdown` the remaining text (placeholders survive — no special chars).
3. Hard breaks: ` {2,}\n` → `<br>`.
4. Emphasis by regex over escaped text: `***`→strong+em, `**`/`__`→strong,
   `*`/`_`→em (underscore word-bounded to avoid intraword), `~~`→del.
5. Restore placeholders.

**Top level** `mdToHtml(src, opts)` — normalize newlines, expand leading tabs,
extract `[ref]: url "title"` definitions, `parseBlocks`, return trimmed HTML.

**`SAMPLE_MARKDOWN`** — a cheat-sheet string exercising every supported construct
(Load sample button).

## 2. `source/app.mjs` — DOM layer

- DOM refs; `state = { syncScroll }`.
- Persistence: `markdown-previewer:v1` = `{ text, syncScroll }` (try/catch, debounced
  save); `markdown-previewer:help-seen:v1` one-shot flag.
- `render()` — `preview.innerHTML = mdToHtml(editor.value)`; debounced on input.
- Toolbar: Load sample (fills editor, renders, saves), Copy HTML (`ctCopy` the
  rendered `preview.innerHTML` + `ctFlash`), Clear (`confirmDialog` → empty editor),
  Sync-scroll toggle (`aria-pressed`, persisted).
- Scroll sync: proportional editor↔preview mapping when enabled, re-entrancy
  guarded.
- Help modal: static markup, first-load auto-show, `?` button, ✕/Esc/backdrop
  close, focus trap + return (mirrors base64-tool).
- `window.__markdownPreviewer = { mdToHtml, escapeHtmlForMarkdown, sanitizeUrl, parseInline,
  render, state }`.

## 3. `source/index.template.html` — shell

`<head>`: charset/viewport, `<title>`, OG + Twitter meta, `<style>` with palette
tokens (light + dark), then `<<ct:include base.css>><<ct:inline styles.css>>`.
`<body>`: header (title + `?`), toolbar, split-pane (editor + preview), help
overlay (with `modal-close-x`), `<<ct:include footer.html>>`,
`<script><<ct:include copy.js>><<ct:include JbcConfirm.mjs>></script>`, and
`<script type="module"><<ct:inline app.mjs>></script>` (app.mjs does
`<<ct:inline logic.mjs>>`).

## 4. `source/styles.css`

Base controls (buttons/inputs, `button:hover:not(:disabled):not(.jbcc-btn)`),
header, toolbar, split-pane grid (two columns → one on ≤760px), editor textarea
(monospace, scrolls), **rendered-preview typography** for both themes (headings,
p, `a`, `strong/em/del`, `code`/`pre` with its own horizontal scroll,
`blockquote`, `ul/ol/li`, `.task-list-item`, `table`/`th`/`td`, `hr`, `img`),
help modal + `modal-close-x`, `--jbcc-*` vars for the confirm dialog, `[hidden]`
guard (also from base.css), responsive tweaks (44px tap targets).
