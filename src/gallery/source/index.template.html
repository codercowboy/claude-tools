claude-tools

A collection of small, single-file, vanilla web tools. Pick one to get started.

🎨 Color Picker Load an image, pan/zoom, and sample pixel colors with a magnifier loupe. Collect them as rgba() and hex. Open → 🔄 Color Converter Convert a batch of intermixed rgba()/hex colors. Type or bulk-paste, see swatches, copy out in either format. Open → 🌈 Color Designer Generate five color schemes from color-theory harmonies — seed your own colors or roll random, preview with a live demo, and copy out. Open → 🔠 Base64 Tool Base64 / data-URI encode & decode — text or a file in; Base64, Base64URL, data URI, or a JS snippet out; and decode back. Open → 🔳 QR Generator Turn text or a URL into a QR code with a hand-rolled encoder, then download it as PNG or SVG. Open → 🆔 UUID Generator Generate UUID v4/v7, ULID, nanoid, and random tokens in bulk, plus a UUID inspector — uses secure randomness. Open → ⏰ Cron Builder Build & parse cron expressions with field pickers, a plain-English explainer, and a next-runs preview. Open → 🌐 Network Toolkit Transfer-time calculator, CIDR/subnet math, IP ⇄ int/hex/binary (v4 & v6), and netmask ⇄ prefix — offline. Open → 💵 Inflation Calculator US inflation between years from bundled BLS CPI-U data — adjusted amount, cumulative % and annual rate. Open → 🖼️ ASCII / Unicode Art Turn an image into text art: ASCII ramp, half-block, Braille, or colored ANSI. Export text, HTML, or ANSI. Open → 🪧 Social Card Maker Compose an Open Graph / Twitter share image with a title, background, and logo. Export PNG, JPEG, or WebP and copy the meta tags. Open → 👾 Dither & Retro-Palette Studio Reduce an image to a limited palette with dithering and chunky pixels. Export PNG, indexed PNG-8, or the palette. Open → #️⃣ Hasher Hash text or a file — MD5, SHA-1/256/512 and CRC32 at once, plus keyed HMAC, with optional Base64 output. Open → 🛡️ HTTP Header Explainer Paste request or response headers to see each explained and checked against a security checklist, or build a recommended set. Never sends a request. Open → 👻 Invisible Chars Find, reveal, and strip zero-width, bidi, and look-alike Unicode hiding in pasted text. Nothing leaves the browser. Open → ▮▯▮ Barcode Generator Make Code 128, EAN-13, UPC-A, or Code 39 barcodes with computed check digits and export crisp SVG or PNG. Nothing leaves the browser. Open → © Batch Watermark Stamp a text or logo watermark on many images at once, then download them as a zip. Resolution-independent sizing, tiling, and PNG, JPEG, or WebP output. Open → 📝 Markdown Previewer Type Markdown, see the rendered HTML live beside it. Hand-rolled converter with link and HTML sanitizing, all local. Open → 🎩 Hat Picker Add entries and pull a random winner from the hat with a slot-machine reveal and confetti. Built for game night. Open → 🔀 Visual Diff Compare two texts side-by-side or inline with word-level highlights and a copyable unified diff. All local. Open → 🔄 Format Converter Convert between JSON, CSV, TSV, YAML, .properties, and XML with auto-detect. Hand-rolled parsers, all local. Open → 🧹 Pretty-Printer & Minifier Format or minify JSON, YAML, HTML, CSS, SQL, and JavaScript. All hand-rolled, all local. Open →
