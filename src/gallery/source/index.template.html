claude-tools

A collection of small, single-file, vanilla web tools. Pick one to get started.

🎨 Color Picker Load an image, pan/zoom, and sample pixel colors with a magnifier loupe. Collect them as rgba() and hex. Open → 🔄 Color Converter Convert a batch of intermixed rgba()/hex colors. Type or bulk-paste, see swatches, copy out in either format. Open → 🌈 Color Designer Generate five color schemes from color-theory harmonies — seed your own colors or roll random, preview with a live demo, and copy out. Open → 🔠 Base64 Tool Base64 / data-URI encode & decode — text or a file in; Base64, Base64URL, data URI, or a JS snippet out; and decode back. Open → 🔳 QR Generator Turn text or a URL into a QR code with a hand-rolled encoder, then download it as PNG or SVG. Open → 🆔 UUID Generator Generate UUID v4/v7, ULID, nanoid, and random tokens in bulk, plus a UUID inspector — uses secure randomness. Open → ⏰ Cron Builder Build & parse cron expressions with field pickers, a plain-English explainer, and a next-runs preview. Open → 🌐 Network Toolkit Transfer-time calculator, CIDR/subnet math, IP ⇄ int/hex/binary (v4 & v6), and netmask ⇄ prefix — offline. Open → 💵 Inflation Calculator US inflation between years from bundled BLS CPI-U data — adjusted amount, cumulative % and annual rate. Open →
