# #1015 · Consolidate Playwright/test deps into root package.json; drop per-tool package.json + lockfiles

- **State:** open
- **Created:** 2026-10-04

**Summary:** Remove each tool's `package.json` + `package-lock.json` and declare the Playwright (and other test) deps ONCE in the root `package.json` with a single root `node_modules`; rework the build/test scripts accordingly. Accepted trade-off (USER decision): lose parallel multi-instance Playwright across separate per-tool installs — fine, since we run one instance at a time and `test-all.mjs` is already sequential (workers:1).

**Context:** Today every tool under `src/tools/*` is a standalone package — its own `package.json`, `package-lock.json`, and isolated `node_modules` (9 tools + the `src/lib/new-tool-template` template; root is deliberately NOT an npm workspace, per `scripts/install-all.mjs`). Each tool declares `@playwright/test` as a devDependency (qr-generator also pulls `jsqr`, `pngjs`, `qrcode` for its e2e specs) and runs `test:e2e` = `playwright test --config=tests/playwright.config.mjs` from its own dir. Per-tool `playwright.config.mjs` stays and would resolve `@playwright/test` from root via normal upward module resolution. Likely-affected scripts: `scripts/install-all.mjs` + root `postinstall`/`install:all` + `ct install` (become no-ops once tools have no package.json — remove/rework so plain root `npm install` suffices); `scripts/test-all.mjs` (discovers tools by `scripts['test:e2e']` and runs `npm run test:e2e` per dir — must invoke Playwright from root instead, e.g. loop `npx playwright test --config=<tool>/tests/playwright.config.mjs` or a single root config globbing all tools); per-tool convenience scripts (build/build:check/test:unit/test:e2e/serve/pre-hooks) vanish with the tool package.json so decide their replacement; `src/lib/new-tool-template` + `scripts/new-tool.mjs` must stop minting a per-tool package.json; non-Playwright test deps (jsqr/pngjs/qrcode) move to root too. `build-all.mjs`/`build-tool.mjs` discover via `source/index.template.html` not package.json, so likely unaffected — confirm.
