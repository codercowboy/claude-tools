**Summary:** The shared `ct` library (`src/lib/`) has NO dedicated unit tests in this repo — add direct unit tests for its pure-logic modules.

**Context:** Confirmed during the #1008 lib-cleanup epic (2026-10-03): zero test files import from `src/lib/utils` or `src/lib/components`. Today the lib is only covered INDIRECTLY and incidentally — each of the 9 tools' unit tests exercises that tool's own bundled `logic.mjs`, and `scripts/tests/` covers the build inliner (38/38) — but nothing tests the lib modules' logic directly. That is a real gap given how much pure, testable logic the lib holds. The DOM-only components (CtConfirm, CtModal, CtClipboardUtil, CtLicense, CtComponents) are currently syntax-checked not executed, and can stay e2e-covered rather than unit-tested.
